# Part 4 – SQL and Spreadsheet Analysis

## Project Name
**TrendPulse – YouTube Trending Analytics**

## Overview
Part 4 focuses on relational database management and spreadsheet-based analysis of YouTube trending video data from India, the United States and Great Britain.

## Section A – SQL Database

**Tool:** MySQL Workbench

### Database
`trendpulse_db`

### Tables
1. `countries` – Stores country information.
2. `categories` – Stores YouTube video categories.
3. `videos` – Stores video details and performance metrics.

### SQL Concepts Implemented
- CREATE DATABASE and CREATE TABLE
- Primary Keys and Foreign Keys
- SELECT and WHERE
- ORDER BY and LIMIT
- DISTINCT and aliases
- GROUP BY and HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

## Section B – Excel Analysis

**Tool:** Microsoft Excel

### Operations Performed
- SUM and AVERAGE
- COUNTIF and COUNTA
- XLOOKUP
- Pivot Tables
- Sorting and filtering
- Conditional formatting
- Named ranges

## SQL and Excel Cross-Verification
Compared record counts, average views and total views between SQL and Excel to verify consistency.

## Dataset
The project uses the cleaned YouTube trending dataset containing 46,000 records across three countries.

## Project Structure
- `data/` – Input datasets
- `sql/` – SQL scripts
- `excel/` – Excel analysis workbook

## Expected Outcome
A structured relational database and spreadsheet analysis that demonstrate SQL querying, data relationships and business-oriented data analysis.
